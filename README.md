# Miguel-Angel-Sanchez-Dionisio-
Miguel Ángel Sánchez Dionisio es futbolista mexicano de Villa Cuauhtémoc, Centla, Tabasco. Volante por derecha o izquierda, perfil derecho y dorsal 8. Actualmente juega con Alebrijes en la Liga TDP, donde disputa su tercera temporada. Comenzó a jugar fútbol a los 6 años.
